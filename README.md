# OpenPdfGuard

OpenPdfGuard is a c++ library and application that converts files to PDF format, can add watermarks, and encrypts PDF files.

## Compiling

```bash
git clone https://github.com/yourname/OpenPdfGuard.git
cd openpdfguard
mkdir build && cd build
cmake ..
make -j$(nproc)
```
